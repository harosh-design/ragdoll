# Ragdoll Volley — Scene & Controls

Minimal scene with one ragdoll (p2-es) and test controls: move left/right and jump.

## Run

```bash
npm install
npm run dev
```

Then open the URL shown (e.g. http://localhost:5173).

## Controls

- **W** — jump  
- **A / Left** — move left  
- **D / Right** — move right  

Settings panel (right): gravity, jump force, move force. Settings can be saved.  

Forces are applied to the ragdoll’s pelvis and upper body.
